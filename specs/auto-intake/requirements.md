# 一站式 Agent 建项

输入：用户自然语言任务描述和资料路径。Agent负责理解、角色识别及只对关键缺项提问；程序负责稳定匹配、目录归档、快照计数、建项/追加。不是要求用户编写JSON或手填表单。

同客户同项目匹配到同一委托/CAT；不同客户不混合。同名不同内容保留版本，不覆盖；同内容重复导入不新增句段。追加保存已有译文、确认状态、批注及Agent历史；项目打开或后台任务进行中时拒绝追加。原文件只复制，不移动。归档按客户/项目/文件角色/批次保存，相对目录保留。

自动填明确字段和空白领域/文本类型，保留来源标记；不覆盖确认值。缺语言/交期/AI政策时返回待补充草稿，缺单价不阻止建项但不乱报金额。新增文件不静默改变已确认报价；提示追加范围待计价。禁止外部AI时仍可归档和建项，不能读取正文分类。

交付：CLI一站式结构化入口供Skill调用、目录清单/归档清单、客户项目匹配、单批多文件创建、后续批次追加、幂等重试、权限检查、真实TXT/DOCX测试及文档。

完成记录：29项自动建项检查通过，包含混合TXT/DOCX追加导出、译文与历史保留、同名版本、源文件保留、跨客户隔离、回滚及幂等。CLI完成分类建议自动填空；语义理解由外部Agent执行，未用真实客户材料调用模型。旧同名未关联项目返回候选，不自动接管。
