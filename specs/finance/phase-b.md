# 商务工作台 B 期

范围：报价参考模板（人工选择、快照）、独立服务订单（无需 CAT 文件）、页/小时/分钟/项等手工计量、工时记录和合同/实收时薪。既有 CAT 流程保持不变。

复查 A 期发现：收款失败后 pending payload 可能使修正金额被拒绝；切换订单没有重置报价表单，容易沿用上一订单单价；刷新列表不刷新当前详情导致冲突难恢复。将这些行为与 B 期一并修正。

验收：无需原文的口译/教学订单可保存、报价和确认；手工计量必须由用户确认且保留来源标记；模板变更不影响已生成报价；计费模式受控，CAT 与服务订单不可在已建项或已有确认报价后互换；客户/币种/服务范围不符合的模板不能静默采用；工时幂等，作废保留记录，0 工时不除零；订单切换不遗留单价和收款请求。

已完成后端与界面实现。验证包含独立服务报价/确认、模板快照、有效期、工时幂等/作废、零工时和时薪，及界面收款拒绝后改正重试。
