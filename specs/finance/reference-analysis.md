## 推荐采用

1. 客户、终端客户分开：付款客户是欠款及合同主体，终端客户用于领域和受众理解，不默认成为付款人。
2. 报价参考库：客户/合作方 + 服务 + 语言方向 + 币种 + 计费口径 + 单价 + 生效期；匹配时只是候选，成交保存快照。
3. 服务订单独立于 CAT 项目：口译、教学、咨询可无源文件；翻译订单可以关联一个或多个 CAT 项目。当前一期要求原文件解析后才能建项，不能覆盖全部业务。
4. 分次收款、客户应收分组、报价单与催款草稿；草稿只生成供用户查看，不自动发消息。
5. 实际工时记录和有效时薪：分别展示合同额/工时与已收净额/工时，工时为零返回未记录，不出现无穷值。

## 不能直接照搬的规则

- 任务状态 pending/in_progress/delivered/paid 混合工作和财务。改为三条独立状态：报价、交付、结算。全额预付不意味着已交付；已交付也不意味着已收款。
- workstation 从 deadline 优先计算账龄并称逾期。应记录 agreedDeliveryAt、deliveredAt、paymentDueAt，逾期仅依据付款到期日；未明确账期时标记待确认。
- 不把“7天/30天”直接当所有客户违约线。风险档位以逾期天数计算，阈值可配置；未到期不会推荐强硬催款。
- 不按任务创建月份统计本月实收。现金流按支付到账日期，接单额按订单确认日期，交付额按交付日期。
- 不能只将超额到账 clamp 为零而隐藏差额。区分 receipt 实收、allocation 分配及 unallocated 未分配余额。多项目一笔转账和预付款保留分配记录。
- 删除支付流水改为冲销/退款事件，保留原流水、理由、日期及关联。不能用手改 paid 状态制造收款事实。
- 保留现有 BigDecimal 计算和幂等键，不沿用浮点金额或前端自报已收合计。
- 多币种按币种分别汇总；没有明确汇率不生成跨币种总额。

## 目标数据结构

- Client：单位、联系人、微信、电话、邮箱、税号、默认币种、账期模板；与 brief 隔离。
- RateCard：clientId/partnerId、serviceType、sourceLocale、targetLocale、basis、per、rate、currency、effectiveFrom/To、notes。
- ServiceOrder：类型、客户/终端客户、语言、领域、交期、交付状态、关联 intakeId/CAT projectId、确认报价快照。
- Quote：revision、lines（数量、单位、单价、费用）、币种、状态、有效期；已成交版本不可静默覆盖。
- Receivable：订单、应收分期、到期日、金额、币种、是否到期。
- Receipt：实际到账事实、币种、金额、日期、渠道、参考号、幂等 ID。
- Allocation：receiptId、receivableId、金额；分配合计不超过该笔净实收，也不超过对应未收。
- Reversal/Refund：关联原事件，不删除原始事实；退款和记账更正分开。
- TimeEntry：订单、日期、分钟数、工作类型、备注。

## 界面

沿用 Projects/Training，再设商务工作窗中的客户、报价参考、订单、应收、收款、统计页签。首屏按币种显示：已确认合同额、未交付待收、已交付未收、已逾期、期间实收、未分配预收。应收按客户分组，可展开订单/分期。接单窗口仍负责材料到 CAT 项目的衔接，不承载所有看板。

## 实现顺序

A. 交付状态与付款状态分离，补实际交付日/到期日；按客户+币种应收看板，按到账日期的期间实收；客户单位/微信/税号和终端客户。
B. 报价参考表和服务明细、多种计费单位、无 CAT 的服务订单、工时和有效时薪。
C. 收款分配、预收余额、跨项目付款、冲销/退款、对账单和催款草稿。
D. 用户需要时才设计飞书/小程序数据导入及同步；先做字段映射与 dry-run，不能直接把现有财务数据合并写入。

## 验收例

- 任务 1000 元，收到定金 300 元但未交付：显示未交付、部分收款、剩余 700，不显示已完成或逾期。
- 10月1日交付，付款到期10月31日：10月16日不是逾期；11月2日逾期2天（按约定时区）。
- 9月创建的订单10月收到款：计入10月现金流，不计入10月新增接单额。
- 同客户一笔1500元：分配订单A 1000、订单B 300，余额200为未分配预收；合计可追溯。
- CNY 和 USD 欠款分别展示，不直接相加。
- 撤销错误收款保留原记录和冲销记录；重复回调不重复入账。
- 历史一期数据迁移时：已确认报价作为合同快照，现有 payments 各转换为 receipt+单订单allocation；交付状态/到期日不猜填，保留原 ID、原始快照和迁移日志。
