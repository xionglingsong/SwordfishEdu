# 材料领域与文本类型分析

已确认范围：逐文件领域、文本类型、依据、人工采纳到 brief；工作台按钮和外部 Agent 共用数据契约。不推断客户未明确的受众或译文用途，不自动推荐风格。

数据：解析快照为真源，analysisId + file SHA-256 + XLIFF SHA-256 约束；每文件分布抽取最多12段，每段最多400 Unicode字符，最多20份源文件。输出覆盖范围，非全文不得标成全文。参考附件不进入分类。

权限：仅显式 aiPolicy=allowed 允许外部分类。请求前、模型返回保存时及采纳时检查；revision 冲突拒绝保存。禁止与 local-only 保守阻断，尚不提供受信任本地分类通道。

校验：每源文件恰好一项，固定字段/长度、枚举、引用段号及原文子串检查。结果只能证明引文存在，不能证明模型判断正确。结果是 suggested，人工采纳后保留前后简报和建议ID；原字段非空须显式替换授权。不同分类按文件列出，unknown 要求手工编辑。

验证：17项 Java 行为检查，3项模拟模型协议/错误测试，真实后端CLI分类保存/采纳，隔离Electron界面流程。未调用付费模型，语义分类准确率未经真实客户材料评估。
